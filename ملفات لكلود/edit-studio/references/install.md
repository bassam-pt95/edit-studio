# التثبيت والتحديث (الخطوة 4)

## وين ينحط كل شي
كل ملفات المستخدم بمكان واحد: مجلد بيانات مهارة المونتاج `<البيانات>` (`VEB_HOME` أو `~/Documents/video-edit`). على ويندوز لو مجلد المستخدم فيه حروف غير إنجليزية، أو OneDrive نقل «المستندات»، يصير المجلد `C:/EditStudio` تلقائياً (OpenCV وmediapipe ما يفتحون المسارات العربية، والمزامنة تقفل الملفات). الاستوديو والمهارة والسكربتات كلها تختار نفس المجلد.

| المجلد | فيه | يُكتب فيه؟ |
|---|---|---|
| `<البيانات>/studio/app/` | الاستوديو نفسه (نسخة من `studio/` و`scripts/` و`manifest.json` و`LICENSE.md`) | **لا. للقراءة فقط** |
| `<البيانات>/studio/projects/` | مشاريع الاستوديو (مشروع لكل مقطع) | نعم، بالأدوات |
| `<البيانات>/studio/home/` | إعداداته (`prefs.json`) وخطوطه وجداول الألوان والأصوات اللي يحفظها من الاستوديو | الاستوديو يكتب فيه |
| `<البيانات>/studio/approved/` | المقاطع اللي يعتمدها من المكتبة («اعتمد…») | الاستوديو ينسخ له |
| `<البيانات>/studio/py/` | بايثون الاستوديو (تنظيف الصوت الكامل، ومشاهد الرسم) | التثبيت فقط |
| `<البيانات>/studio/server.log` | سجل التشغيل | الاستوديو |
| `~/Desktop/B Studio.app` | تطبيق سطح المكتب: يشغّل الاستوديو ويفتحه | التثبيت فقط |
| `~/Desktop/B Studio.lnk` (ويندوز) | اختصار سطح المكتب: يشغل الاستوديو ويفتحه | التثبيت فقط |
| `<البيانات>/studio/launch-studio.js` (ويندوز) | اللي يشغله الاختصار بـ wscript: يشغل الاستوديو بلا نافذة طرفية (يكتبه `make-app.sh`، برا `app` فما تنفحص بصمته) | التثبيت فقط |

مجلدات شغل المونتاج تبقى مكانها (`<البيانات>/projects/<المقطع>/`)؛ الاستوديو يقرأ منها وما يكتب فيها شي.

ويندوز: قفل القراءة (`chmod`) ما يمنع اضافة ملفات، بس يمنع الحذف ببايثون (`shutil.rmtree`) او PowerShell بدون `-Force`. للحذف بيدك: `chmod -R u+w "<البيانات>/studio/app"` ثم احذف، او من PowerShell: `Remove-Item -Recurse -Force` (وشيل وصلة `node_modules` قبل لو فيه وحدة).

## الأوامر
```bash
bash "<المهارة>/scripts/setup.sh"              # فحص فقط: 0 جاهز · 10 فيه مطلوب · 11 أدوات المونتاج ناقصة · 20 جهاز غير مدعوم
bash "<المهارة>/scripts/setup.sh" --install    # بعد موافقته: يثبّت أو يحدّث، ثم يشغّل التشخيص
#   --no-python  بلا أدوات الصوت (لو الإنترنت ضعيف؛ الاستوديو يعمل والتنظيف «خفيف» بس)
#   --no-app     بلا تطبيق سطح المكتب
```
وش يسوي `--install` بالترتيب:
1. ينسخ الحزمة إلى `studio/.app-new`، يشيل علامة «من الإنترنت» عن الملفات، ويتحقق من سلامتها بالبصمات (`manifest.json`). الحزمة نفسها معدّلة؟ يوقف ويطلب الحزمة الأصلية.
2. يوقف الاستوديو لو شغّال (الاستوديو حقّه بس)، يبدّل النسخة القديمة بالجديدة، ويقفلها للقراءة.
3. يجهّز مجلدات البيانات والإعدادات الافتراضية (ما يمسح أي إعداد موجود).
4. بايثون الاستوديو: `python3 -m venv` (ويندوز: `python -m venv` ببايثون مهارة المونتاج، والبايثون في `studio/py/Scripts/python.exe`) ثم الحزم من `studio/voice/requirements.txt` (~550 ميقا من الإنترنت؛ فيها مكتبة تنظيف الضجيج DPDFNet، ونموذجها نفسه داخل الحزمة).
5. تطبيق «B Studio» على سطح المكتب.
6. التشخيص (`doctor.sh`).

## التحديث
يقول «حدّث الاستوديو»: الخطوة 0ج (`update.sh` ينزّل آخر نسخة من المستودع ويشغّل `install.sh` حقها، فيبدّل المهارتين والقديمة لسلة المهملات، وعلى ويندوز لمجلد `%USERPROFILE%\edit-studio-old`، وكل تحديث يزيد فيه نسخة بتاريخها، يقدر يمسحها بعد ما يتاكد ان الجديدة شغالة) ثم 1 إلى 4 من SKILL.md كما هي. بدون نت: ينزّل الملف بيده ثم 0ب.
`setup.sh` يقارن النسختين ويطبع «تحديث الاستوديو من X إلى Y». المشاريع والإعدادات ما تنلمس.
التثبيت يوقف الاستوديو لو كان شغّال. بعده: لو كان فيه مقطع مفتوح، افتحه من جديد (`bash "$S/studio.sh" open "<المشروع>"`) وقل له يحدّث الصفحة (⌘R، ويندوز: Ctrl+R او F5).

## المكوّن الإضافي لمحادثات Claude Code
`install.sh` يسجّل داخل مجلد المهارة سوقاً صغيراً اسمه `edit-studio` (الملف `.claude-plugin/marketplace.json`) ويركّب منه المكوّن `edit-studio@edit-studio`. المكوّن يقرا من مجلد المهارة نفسه، فالتحديث يكفيه، وإعادة التركيب ما تضر. يعطي أي محادثة من Claude Code أدوات الاستوديو (`project_summary` و`apply` و`draw` وغيرها)، وحارس يمنع كتابة `project.json` و`plan.json` من خارج الاستوديو، وملف مهارة قصير `studio-chat` يشرح الطريقة.
لو ما انركّب (claude غير موجود، أو رفض الأمر) شغّل بنفسك:
```bash
claude plugin marketplace add "$HOME/.claude/skills/edit-studio"
claude plugin install edit-studio@edit-studio
```
(مع `CLAUDE_CONFIG_DIR` إذا غيّر المستخدم مكان إعدادات كلود.) والمحادثة تلقى الاستوديو الشغّال بنفسها (المنفذ 8795 وما بعده).

## التشغيل
- المستخدم: يضغط «B Studio» على سطح المكتب.
- أنت: `bash "$S/start.sh"` (يفتح المتصفح) أو `bash "$S/start.sh" --no-open`. يطبع «الاستوديو يعمل: <العنوان>».
- المنفذ 8795، ولو مشغول يأخذ اللي بعده. الأدوات تلقى الاستوديو بنفسها (ما تحتاج تعرف المنفذ).
- الإيقاف: `bash "$S/studio.sh" stop`.
- وضع الجوال على ويندوز: اول مرة يطلب جدار الحماية اذن لـ node.exe: اختر الشبكات الخاصة (Private) بس، وخل شبكة البيت Private، وسكر وضع الجوال بعد ما تخلص. Cancel يسوي قاعدة منع لـnode.exe تغلب اي سماح بعدها، فالجوال ما يوصل لين يشيلها من اعدادات جدار الحماية.
- ويندوز: قبل ما تنقل او تسمي او تحذف مجلد البيانات، اوقف الاستوديو (`bash "$S/studio.sh" stop`): الاستوديو الشغال ماسك `server.log`، فالنقل يفشل.
